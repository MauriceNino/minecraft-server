title: Server Platforms

`MauriceNino/minecraft-server` downloads, updates and starts your server software. It verifies downloads against the
checksums the platform publishes, starts Java servers with tuned [JVM flags](../environment#jvm-options) and warns when
the image's Java version doesn't fit your Minecraft version.

## Supported Platforms

You can control which software runs via the `TYPE` environment variable.

### Game Servers

- [**PAPER**](paper): High-performance Spigot fork. Recommended for most plugin-based servers.
- [**PURPUR**](purpur): High-performance Paper fork with additional configurability and features.
- [**FOLIA**](folia): Regionized multithreading Paper fork for massive player counts.
- [**VANILLA**](vanilla): The official server software from Mojang. Reliable and pure, but lacks plugin support.
- [**SPIGOT**](spigot): The most popular plugin-compatible fork of CraftBukkit.
- [**BUKKIT**](bukkit): The classic CraftBukkit server software.
- [**PUMPKIN**](pumpkin): High-performance Rust-based server with native plugin support.
- [**CUSTOM**](custom): Any other server JAR, from a URL or a file.

### Proxies

- [**VELOCITY**](velocity): The next-generation proxy for maximum performance and stability.
- [**WATERFALL**](waterfall): A high-performance fork of BungeeCord, compatible with Bungee plugins. End of life
  upstream.
- [**BUNGEECORD**](bungeecord): The original proxy from SpigotMC.

## Version Resolution

`VERSION` and `BUILD` take a specific value or one of these aliases:

- **`latest`** (or `stable`, the default): the newest stable version or build.
- **`experimental`** (or `beta`): also allows snapshots, pre-releases and beta builds, where the platform has them.

| Platform            | Source                  | `VERSION` example | `BUILD`                   |
| ------------------- | ----------------------- | ----------------- | ------------------------- |
| Paper, Folia        | PaperMC API             | `1.21.4`          | Build number, e.g. `232`  |
| Velocity, Waterfall | PaperMC API             | `3.4.0`, `1.21`   | Build number              |
| Purpur              | Purpur API              | `1.21.4`          | Build number, e.g. `2416` |
| Vanilla             | Mojang version manifest | `1.21.4`          | Not used                  |
| Spigot, Bukkit      | getbukkit.org           | `1.21.4`          | Not used                  |
| BungeeCord          | SpigotMC Jenkins        | Ignored           | Jenkins build number      |
| Pumpkin             | GitHub releases         | `latest`          | Not used                  |
| Custom              | `CUSTOM_JAR`            | `1.21.4`          | Not used                  |

The resolved version and build are stored in `runtime/server-lock.json`. The server is only downloaded again when they
change or when the installed file was deleted or modified. If the API is unreachable, the installed server starts as
long as it matches your `VERSION` and `BUILD`.

## Configuration

Each platform supports a tailored set of environment variables for versioning and execution. Read the documentation for
your specific platform to see available versions and default execution behaviors.
