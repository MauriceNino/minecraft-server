**Purpur** is a drop-in replacement for Paper that aims for configurability, new fun and exciting gameplay features, and
high performance. It includes all the features and performance optimizations of Paper and Spigot.

## Configuration

Set `TYPE=PURPUR` to use this platform.

```yaml
environment:
  TYPE: PURPUR
```

- **`VERSION`**: The game version (e.g., `1.21.4`), or `latest` (default) for the version Purpur marks as current.
- **`BUILD`**: The build number (e.g., `2416`), or `latest` (default). Purpur has no release channels, so `experimental`
  is the same as `latest`.
- **`MEMORY`**: Defines the heap size (e.g., `2G`, `512M`). Default is `1G`.
- **`JVM_FLAGS`** / **`JVM_EXTRA_FLAGS`**: Replace or extend the default JVM flags. See
  [JVM Options](../../environment#jvm-options).

The orchestrator automatically fetches the latest builds from the [Purpur API](https://api.purpurmc.org/v2/purpur).

## RCON Support

The orchestrator automatically injects the necessary RCON settings (port and password) into your `server.properties`
file at startup.

See [RCON Variables](../../environment#rcon-variables) for configuration details.
