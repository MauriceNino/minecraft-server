---
title: Folia
description: Regionized multithreading Paper fork
---

**Folia** is a fork of Paper that groups nearby players into independent "regions". Each region has its own tick loop,
which runs on its own thread, allowing for massive player counts on a single server.

Folia is specifically designed for servers with 100+ players and great server hardware. If you have fewer players, Paper
is usually more efficient.

## Configuration

Set `TYPE=FOLIA` to use this platform.

```yaml
environment:
  TYPE: FOLIA
```

- **`VERSION`**: The game version (e.g., `1.21.4`), or `latest` (default). `experimental` also allows `-SNAPSHOT`
  versions.
- **`BUILD`**: The build number (e.g., `123`), or `latest` (default) for the newest stable build. `experimental` also
  allows beta and alpha builds.
- **`MEMORY`**: Defines the heap size (e.g., `4G`). Default is `1G`.
- **`JVM_FLAGS`** / **`JVM_EXTRA_FLAGS`**: Replace or extend the default JVM flags. See
  [JVM Options](../../environment#jvm-options).

The orchestrator automatically fetches the latest builds from the
[PaperMC API](https://fill.papermc.io/v3/projects/folia).

## RCON Support

The orchestrator automatically injects the necessary RCON settings (port and password) into your `server.properties`
file at startup.

See [RCON Variables](../../environment#rcon-variables) for configuration details.
