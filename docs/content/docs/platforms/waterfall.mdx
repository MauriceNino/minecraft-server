**Waterfall** is a fork of BungeeCord, the popular Minecraft proxy. It is designed for performance and stability while maintaining full compatibility with BungeeCord plugins.

## Configuration

Set `TYPE=WATERFALL` to use this platform.

```yaml
environment:
  TYPE: WATERFALL
```

- **`VERSION`**: Resolves the proxy version (e.g., `1.21`, `latest`).
- **`MEMORY`**: Defines the heap size (e.g., `2G`). Default is `1G`.
- **`JVM_FLAGS`** / **`JVM_EXTRA_FLAGS`**: Replace or extend the default JVM flags. See [JVM Options](../../environment#jvm-options).

The orchestrator resolves builds via the [PaperMC API](https://api.papermc.io/v2/projects/waterfall).

## RCON Support

Waterfall has no built-in RCON. The orchestrator installs the [bungee-rcon](https://github.com/orblazer/bungee-rcon) plugin and configures its port and password.

See [RCON Variables](../../environment#rcon-variables) for configuration details.
