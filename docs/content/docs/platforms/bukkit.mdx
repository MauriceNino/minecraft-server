**Bukkit** (specifically CraftBukkit) is the classic plugin-capable Minecraft server software. While mostly superseded by Spigot and Paper, it is still supported for legacy purposes.

## Configuration

Set `TYPE=BUKKIT` to use this platform.

```yaml
environment:
  TYPE: BUKKIT
```

- **`VERSION`**: Resolves the game version (e.g., `1.8.8`, `latest`).
- **`MEMORY`**: Defines the heap size (e.g., `1G`). Default is `1G`.
- **`JVM_FLAGS`** / **`JVM_EXTRA_FLAGS`**: Replace or extend the default JVM flags. See [JVM Options](../../environment#jvm-options).

<Callout title="Best effort" type="warn">
  Spigot and CraftBukkit don't publish server JARs. The orchestrator downloads them from getbukkit.org, an
  unofficial third-party mirror without checksums, so downloads can break when the site changes. Prefer
  [Paper](../paper) if your plugins support it.
</Callout>

## RCON Support

The orchestrator automatically injects the necessary RCON settings (port and password) into your `server.properties` file at startup.

See [RCON Variables](../../environment#rcon-variables) for configuration details.
