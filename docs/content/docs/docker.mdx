The orchestrator is built primarily to work gracefully within Docker environments, particularly `docker-compose`.

## Minimal Setup

A `docker-compose.yml` deploying a basic Paper server looks like this:

```yaml
services:
  minecraft:
    image: ghcr.io/mauricenino/minecraft-server:latest
    environment:
      TYPE: PAPER
      VERSION: latest
      MEMORY: 2G
      ACCEPT_EULA: true
      PLUGINS: |
        modrinth:luckperms@latest
        hangar:viaversion@latest
    volumes:
      - ./data:/data/runtime
    ports:
      - '25565:25565'
```

## Shutdown

On `docker stop`, the server gets a `SIGTERM` and saves its worlds before exiting. Docker kills the container
after 10 seconds by default, which is often not enough for larger worlds. Raise the limit per service:

```yaml
services:
  minecraft:
    stop_grace_period: 2m
```

## Health Check

The image has a `HEALTHCHECK` that sends a Minecraft status ping to the server, so `docker ps` shows the
container as `healthy` once players can connect. You can run it manually with
`docker exec <container> mc-orchestrator healthcheck`.

The address and port are read from the server's config (`server-ip` and `server-port`, or the proxy's bind
address). With `enable-status=false` the server doesn't answer status pings, so the check only tests that the
port accepts connections.

## Volumes & State

Inside the container, `/data` is the target directory via `DEFAULT_DATA_DIR`.

- `/data/runtime`: Where the server execution happens (and where you should mount to persist data).
- `/data/templates`: Where you should mount your config skeletons.

## Image Flavors

We provide a variety of Docker image flavors to suit your needs, varying by Java version and distribution.

### Java Versions

- **Java 25** (Default)
- **Java 23**
- **Java 21**
- **Java 17**, **Java 11** and **Java 8** (Temurin only), for Minecraft versions before 1.17

Minecraft 26.1 and newer need Java 25, 1.20.5 - 1.21.11 need Java 21, 1.18 - 1.20.4 need Java 17. Versions
before 1.17 often don't run on anything newer than Java 17, and 1.12 and older need Java 8. The orchestrator
prints a warning on startup when the image's Java doesn't fit your `VERSION`.

### Java Distributions

You can choose from several popular Java distributions:

- **Temurin** (Default, via Eclipse Adoptium)
- **Corretto** (Amazon)
- **Microsoft**
- **Azul** (Zulu)
- **GraalVM** (Oracle)

### Tagging Scheme

Tags follow the pattern `java<version>-<distribution>`.

| Feature          | Tag Example                 |
| ---------------- | --------------------------- |
| Latest Stable    | `latest` (Java 25, Temurin) |
| Specific Version | `java21-temurin`            |
| Different Flavor | `java25-graalvm`            |

> [!TIP]
> If you are unsure which one to use, `latest` (Java 25 Temurin) is recommended for most users.
